## Open Source — Epic County Ecosystem

A unified toolchain for AI-native development, installed and managed via the [`epiccounty`](https://github.com/epiccounty/epiccounty.com) CLI.

> Tools are currently published under [`@epicsagas`](https://github.com/epicsagas) and migrating to the Epic County brand as it matures.

**Foundation**
- [**llm-kernel**](https://github.com/epicsagas/llm-kernel) — Rust foundation for AI-native apps

**Platforms**
- [**epic-harness**](https://github.com/epicsagas/epic-harness) — self-evolving AI agent harness
- [**alcove**](https://github.com/epicsagas/alcove) — private doc server & MCP context for agents
- [**Episteme**](https://github.com/epicsagas/Episteme) — software-engineering knowledge graph

**CLI Tools**
- [**claudy**](https://github.com/epicsagas/claudy) — multi-provider AI launcher
- [**obsidian-forge**](https://github.com/epicsagas/obsidian-forge) — Obsidian vault automation

**Libraries**
- [**llm-transpile**](https://github.com/epicsagas/llm-transpile) — token-optimized document transpiler
